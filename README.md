# 🎮 Tic Tac Toe

A simple and responsive **Tic Tac Toe game** built using HTML, CSS, and JavaScript.

## ✨ Features

- 👥 Two-player gameplay
- ❌ Player X and ⭕ Player O turns
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Restart Game button
- 📱 Responsive design
- 🎨 Simple and clean UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 How to Play

1. Player X starts the game.
2. Players take turns clicking an empty cell.
3. The first player to get three symbols in a row wins.
4. The game can end in:
   - Row
   - Column
   - Diagonal
5. If all cells are filled and nobody wins, the game ends in a draw.
6. Click **Restart Game** to play again.
